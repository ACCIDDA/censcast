# Toy weekly census history

Synthetic weekly census counts in the standard hubverse target data
shape, generated by convolving
[admission_history](https://accidda.github.io/censcast/reference/admission_history.md)
with a "true" length of stay distribution (`negbin(mu = 2, k = 1.7)`).
Pair with
[admission_history](https://accidda.github.io/censcast/reference/admission_history.md)
as input to
[`fit_los()`](https://accidda.github.io/censcast/reference/fit_los.md)
or use as truth in
[`score_census()`](https://accidda.github.io/censcast/reference/score_census.md).

## Usage

``` r
census_history
```

## Format

A tibble with columns `target_end_date`, `target`, `location`,
`observation` (weekly census, not admissions).

## Details

Hubs publish admissions truth, not census truth. In a real workflow you
supply census from your own hospital records.
